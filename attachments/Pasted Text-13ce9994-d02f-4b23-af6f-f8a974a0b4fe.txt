# 專案概述
請幫我開發/升級一個基於 React 的「極簡本地影音播放器 (Local Media Player)」。這個播放器需要支援本地端上傳音檔與影片檔，具備高度客製化且極簡的深色系 UI，並擴充多項專業播放器應有的進階功能。

## 🛠 技術棧 (Tech Stack)
*   **前端框架**：React 18 + TypeScript + Vite
*   **樣式庫**：Tailwind CSS (深色模式設計)
*   **圖示庫**：Lucide React
*   **媒體處理**：HTML5 `<video>` / `<audio>` API / Web Audio API (完全客戶端運作，無後端)

## 📂 專案目錄與基礎架構
*   `src/App.tsx`: 應用程式主入口。負責畫面佈局、本地檔案載入 (`URL.createObjectURL`) 與播放清單狀態管理。
*   `src/components/MediaPlayer.tsx`: 核心客製化播放器組件。封裝 HTML5 媒體元素，並完全自訂播放控制列。

## ✨ 已完成之基礎功能 (Base Features)
1.  **本地檔案讀取**：可透過 `<input type="file">` 載入本地 `.mp4`, `.mp3`, `.wav` 等檔案。
2.  **客製化播放器介面 (MediaPlayer)**：
    *   支援影片與純音訊雙模式 (音訊模式顯示客製化背景與圖示)。
    *   滑鼠閒置超過 2.5 秒自動隱藏控制列 (Auto-hide)。
    *   基礎控制：播放/暫停、進度條跳轉、靜音切換、全螢幕切換、時間顯示。

## 🚀 核心擴充任務 (請 Manus 協助實作以下功能)

請基於上述基礎，幫我實作以下進階功能，讓它成為一個完整的萬能播放器：

### 1. 播放清單與拖曳支援 (Playlist & Drag-and-Drop)
*   **多檔案匯入**：允許使用者一次選擇多個影音檔案，或直接將檔案「拖曳 (Drag & Drop)」到網頁視窗內加入。
*   **播放清單 UI**：在播放器側邊或底部建立一個可收合的播放清單 (Playlist) 列表，支援點擊切換曲目/影片。
*   **自動連播**：當前媒體播放完畢後，自動播放清單中的下一首。

### 2. 全面鍵盤快捷鍵 (Keyboard Shortcuts)
*   `Space (空白鍵)`：播放 / 暫停。
*   `← / → (左右方向鍵)`：快退 / 快轉 (例如每次 5 秒)。
*   `↑ / ↓ (上下方向鍵)`：音量調大 / 調小。
*   `F` 鍵：切換全螢幕。
*   `M` 鍵：靜音 / 解除靜音。

### 3. 進階播放控制與畫中畫 (Advanced Playback & PiP)
*   **播放速度控制 (Playback Speed)**：在控制列新增速度選單 (0.5x, 1.0x, 1.25x, 1.5x, 2.0x)。
*   **子母畫面 (Picture-in-Picture)**：新增 PiP 按鈕，呼叫瀏覽器的 `requestPictureInPicture()` API，讓影片可以浮動在系統視窗最上層。

### 4. 字幕支援 (Subtitles Support)
*   新增「載入字幕」按鈕，允許使用者選擇本地的 `.srt` 或 `.vtt` 檔案。
*   將解析後的字幕同步顯示在影片畫面的底部，並允許調整字幕大小。

### 5. 系統媒體控制整合 (Media Session API)
*   介接 `navigator.mediaSession`，讓使用者即使將網頁縮小，也能透過電腦鍵盤上的實體媒體鍵 (上一首/下一首/暫停) 來控制播放器，並在系統鎖定畫面顯示當前播放的檔名。

### 6. 音訊視覺化 (Audio Visualizer) - (選配加分功能)
*   當播放的是**純音訊 (Audio)** 時，利用 `Web Audio API` 與 `<canvas>`，在黑底畫面中繪製動態的音頻頻譜 (Audio Spectrum) 或波形圖，增加視覺豐富度。

### 7. 使用者偏好記憶 (Local Storage)
*   使用 `localStorage` 記住使用者最後設定的**音量**與**播放速度**，下次開啟網頁時自動套用。

## 🎨 UI/UX 設計規範維持
*   維持 `#050505` 極簡深色背景。
*   控制列使用毛玻璃 (Backdrop Blur) 與黑色漸層，確保控制項不干擾影片內容。
*   按鈕互動保持滑順的過渡動畫 (Tailwind `transition-all`)。
